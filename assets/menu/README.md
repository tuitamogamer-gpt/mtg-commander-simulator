# Landing imagery

The existing `invisible-woman.webp`, `galadriel-elven-queen.webp`, and
`zimone-infinite-analyst.webp` are the original Scryfall card images. Their image
files are unchanged by the Command Table redesign.

`command-table-preview.jpg` and `command-focus-preview.jpg` are unaltered
Chromium screenshots of the real interface at 1440 × 1024. The mobile preview
is captured at 390 × 844. Captured on 2026-09-05 using the public board fixture
from `tests/browser/command-table.mjs`: turn 8, Beast Within targeting the human
player's Sol Ring. JPEG quality: 85. The card and commander artwork in all
three screenshots comes from the existing Scryfall image resolver/local copies.
The files illustrate the interface, not a saved or currently active game.

Card and commander illustrations remain original Scryfall imagery. Screenshots
should be recaptured when the interface changes.

The 2026-09-09 landing uses `ember-slate.jpg`, an original environmental background
created with the built-in image-generation tool. It is not card or commander art.
The generated 1916 × 821 image was encoded as JPEG (quality 82, approximately
410 KB). The original remains in the Codex generated_images folder.

Generation prompt: Create an ultrawide cinematic environmental background texture
for a premium fantasy trading card game website hero, aspect ratio 21:9. Fractured
obsidian slate, charcoal blue-black stone, sparse glowing copper-orange fissures
on the right half, subtle ash, dramatic low-key light. Keep the left half dark
and quiet for typography. No text, logos, cards, characters, faces, dragons,
weapons, UI, screens, circles, portals, or fake screenshots. Background only.

The collection uses existing local Scryfall art crops for Galadriel, Elven-Queen;
Prosper, Tome-Bound; and Abaddon the Despoiler. Selecting one opens its built-in
deck in Solo setup and preserves that choice through first-game onboarding.
