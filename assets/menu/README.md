# Landing imagery

The existing `invisible-woman.webp`, `galadriel-elven-queen.webp`, and
`zimone-infinite-analyst.webp` are the original Scryfall card images. Their image
files are unchanged by the Command Table redesign.

`command-table-preview.jpg` and `command-focus-preview.jpg` are unaltered
Chromium screenshots of the real interface at 1440 × 1024. The mobile preview
is captured at 390 × 844. Captured on 2026-09-05 using the public board fixture
from `tests/browser/command-table.mjs`: turn 8, Beast Within targeting the human
player's Sol Ring. JPEG quality: 85. The card and commander artwork in all
three screenshots comes from the existing Scryfall image resolver/local copies.
The files illustrate the interface, not a saved or currently active game.

No generated card art, generated commander art, or concept illustration is used
by this landing page. Screenshots should be recaptured when the interface changes.
