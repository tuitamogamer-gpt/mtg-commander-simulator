# Commander card backs

Original artwork generated with OpenAI ImageGen on 2026-10-17 for the Commander UI refresh, at the user's explicit request. These images are cosmetic card **backs**, not card faces or commander illustrations. Existing card faces and commander art continue to use Scryfall.

## Assets

| Theme | Runtime asset | Dimensions | Bytes | Art direction |
| --- | --- | --- | ---: | --- |
| Obsidian | `obsidian.webp` | 600 × 840 | 119,614 | Dark emerald obsidian, antique brass, restrained ember details. |
| Astral | `astral.webp` | 600 × 840 | 166,054 | Midnight indigo starstone, silver and pale cyan. |
| Ember | `ember.webp` | 600 × 840 | 149,976 | Black basalt, aged copper and amber light. |

The unmodified 1,060 × 1,484 ImageGen PNG outputs are retained in `originals/`. Runtime code should request only the WebP assets. All images have a 5:7 portrait aspect ratio and fill the rectangular canvas without a staged card mockup or surrounding whitespace.

## Generation provenance

The original Obsidian prompt requested a premium full-bleed flat card back: a centered symmetric elongated compass-diamond sigil, four balanced points, fine orbital rings and etched filigree, dark tactile stone, a thin double metallic border, quiet negative space and a clear thumbnail silhouette. It explicitly excluded words, letters, numbers, runes, watermarks, logos, Magic branding, official mana symbols, pentagrams, characters and existing franchise card-back designs.

Astral and Ember were generated by ImageGen using the original Obsidian output as a reference. Each retained the series' frame, composition and central emblem while transforming the palette and materials described above. All three generated results were visually inspected before conversion.

The only post-generation processing was proportional downsampling, metadata removal and WebP encoding. No retouching, compositing, creative edits or palette changes were applied outside ImageGen.

To reproduce the optimized files with ImageMagick:

```sh
for theme in obsidian astral ember; do
  magick "originals/$theme.png" -resize 600x840 -strip -quality 88 \
    -define webp:method=6 "$theme.webp"
done
```

## Presentation constraints

- Hidden cards wear their owner's deck sleeve, drawn at runtime by `src/modules/deck-sleeves.js` from the chosen back and the owner's public deck identity: commander art from the existing Scryfall art crops and the commanders' color identity. The back files themselves are unchanged.
- Never select or alter a back from a card's identity, color, type, mana value or other concealed information. Unknown or random decks keep the plain design.
- Card backs contain no gameplay information and must not disclose an image URL or accessible label derived from a concealed card face.
- Preserve the 5:7 aspect ratio. Rounded corners and reveal transitions belong to the existing UI presentation.
